# Дух Свободы • App (preview)

Отдельный адаптивный фронтенд для сообщества. Не использует фиктивные данные профиля: до появления авторизованного API раздел отображает честное состояние «скоро».

## Разработка
Node.js 22+:
```bash
cd app
npm install
npm run dev
npm run build
```

В продакшене разместите собранную папку `dist/` на HTTPS-домене, а URL этого домена укажите в переменной `SPIRIT_APP_URL` **бота**. В `/admin` появится раздел «Spirit App», где можно выбрать канал для публикации ссылки. В этой версии кнопка ведёт на HTTPS-сайт, **не является Discord Activity**.

Сейчас `/api/me` не реализован, поэтому UI специально не показывает чужие профили и не доверяет клиентским данным. Перед внедрением API требуется Discord OAuth2 с проверкой `state`, серверная сессия, привязка guild/user и безопасный доступ к базе бота. Не передавайте `DISCORD_TOKEN` в приложение или браузер.
